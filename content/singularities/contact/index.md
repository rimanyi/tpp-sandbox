# Contact singularities


## List of the singularities in Mather's nice dimensions

<div class="wp-content" markdown="0">
A complete and repetition-free list of complex algebras corresponding to the singularities in Mather's nice dimensions, for l&#x2265;0. Recall, that the Mather bond is 6l+8 for l=0,1,2,3, and it is 6l+7 if l&gt;3. 

The list contains 55 algebras.

For each algebra below there is a nonempty set of l's for which that algebra appears corresponding to a singularity C^*-&gt;C^{*+l} in the nice dimension range.

Notation: d_i = dim_C(m^i/m^{i+1}) for i=1,2,...

\(\Sigma^I\): Thom-Boardman symbol

For a concrete l&#x2265;0, a subset of these algebras appear.<ul> For example, for l=0 <a href="@ROOT@/files/hierarchy.pdf">these</a>.</ul><ul> For example, for l=1 <a href="@ROOT@/files/HierarchyRelativeDimension1.pdf">these</a>. </ul><ul> For l&#x2265;18, all but the last seven algebras appear. </ul><span>Names.</span> Some algebras have standard names: A_k, I_{a,b}=I_{ab}, III_{a,b}=III_{ab} (we suppress commas when convenient). For the rest we suggest a name in <span>red</span> below. In these names A, B, C, D, E refer to Thom-Boardman symbols  \(\Sigma^1, \Sigma^2, \Sigma^3, \Sigma^4, \Sigma^5\). The first number after the letter refers to \(\mu\). The second number is simply the position in our list. For example <span>C_{52}=C_{5,2}=C(5,2)=C52</span> is the 2nd algebra listed with \(\Sigma^3\), \(\mu=5\).<hr>[Mather] J.
