# About the portal

The Thom Polynomial Portal is maintained by [Richárd Rimányi](https://rimanyi.web.unc.edu/) (UNC Chapel Hill).
It started in 2018 as a WordPress site at [tpp.web.unc.edu](https://tpp.web.unc.edu/) and moved to GitHub in 2026.

## How to cite

## How the site is made

All mathematical data lives in small plain-text files in the folder `data/` of the GitHub repository, one file per
singularity, kind of data and relative dimension. The pages are generated from these files (and from the
hand-written pages in `content/`) every time something changes, so the singularity pages, the tables and the state of
knowledge never disagree. Every change is recorded in the repository's history.
